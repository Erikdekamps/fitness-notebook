# Font

`caveat-latin.woff2` is the Latin subset of **Caveat**, the handwriting font the app uses.

- Designed by Pablo Impallari (Impallari Type). Copyright the Caveat Project Authors.
- Licensed under the SIL Open Font License, version 1.1: https://openfontlicense.org
- Source: https://fonts.google.com/specimen/Caveat

It is a variable font covering weights 400 to 700. `index.html` loads it with `@font-face`.
